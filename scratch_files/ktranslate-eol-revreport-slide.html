GTM REV REPORT

kTranslate Agent
EOL

kTranslate, the NPM data collection agent, will EOL on [DEADLINE DATE]. Customers move to the New Relic Network Agent, available on Docker Hub from [ANNOUNCEMENT DATE].

What changesWhat stays the same
  • newrelic/network-agent:latest replaces kentik/ktranslate:v2
  • Docker only: Podman and Linux package installs move to Docker
  • Two config paths: /etc/ktranslate becomes /etc/network-agent
  • Agent health data: collector.name is now network-agent
  • Device entities, their history, and kentik.* metrics, so device dashboards and alerts keep working
  • License key, account, region, and the rest of the docker run command
  • Cloud flow logs (AWS, Azure, GCP) aren't affected

Customer Action is Required.
Customers update two config paths and re-create each container on the new image, with a minute or two of data gap per container.

Account Teams: Help NPM customers plan the switch early. Fixes, security updates, and upcoming agent-management tools ship only in the new agent.
